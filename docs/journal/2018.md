# 2018 journal

## Day 1

- **Key idea:** part 2 never simulates the repeating stream. Each later
  frequency is a one-cycle prefix plus a whole number of cycle drifts, so two
  prefixes collide only when their difference is divisible by the drift. The
  earliest valid (cycles, position) pair gives the first repeat, and an input
  with no valid pair provably never repeats, so the search always terminates.
- **Surprise:** some part-1 examples never repeat under part 2. Those inputs
  render part 1 only, so the part-1 fixtures stay valid.
- **Primary measurement** (x86_64 Linux, pinned CPU 0): work median 93.5 M
  user-space instructions [92.8 M, 107.5 M], wall median 5.0 ms, peak RSS
  2208 KiB. The quadratic prefix-pair scan dominates; a hash map keyed by
  residue modulo drift would make it near-linear and is a candidate
  exploration.
